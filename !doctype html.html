简介

自己思考是一个零参数、零算力、零训练、零推理的下一代大模型。 它不生成答案，它只是答案的搬运工。

传统模型通过权重推理产生输出。自己思考把推理步骤外包给调用方用户本身， 服务端只负责一次 prompt 转发。因此：

  • 没有 GPU，没有权重，没有推理时间
  • 可解释性 100%，因为推理过程就是你自己的思考过程
  • 零幻觉，所有幻觉由用户负责
  • 完全免费，真的免费
  • 内置超时机制，用户犹豫不决时返回 408
i
一句话理解：输入 X → 弹窗 X → 你回答 Y → 输出 Y。超时不答，返回 408。

快速开始

不需要 API Key。不需要注册。浏览器打开就能跑。

最小可用代码，带超时：

JavaScript 
// 自己思考 · 最小实现（带超时）
function selfThink(input, timeoutSec = 15) {
  return new Promise(resolve => {
    let done = false;
    const timer = setTimeout(() => {
      if (done) return;
      done = true;
      resolve({ ok: false, code: 'USER_TIMEOUT', status: 408 });
    }, timeoutSec * 1000);

    // 真实实现里此处弹出自定义模态框
    const Y = prompt(input);
    if (done) return;
    done = true;
    clearTimeout(timer);

    if (Y === null) {
      resolve({ ok: false, code: 'USER_CANCELLED', status: 499 });
    } else {
      resolve({ ok: true, answer: Y });
    }
  });
}

selfThink("现在是北京时间多少点？", 15)
  .then(r => console.log(r.ok ? r.answer : r.code));
!
为什么需要自定义弹窗：原生 prompt() 会阻塞主线程且无法自动关闭，因此生产实现应使用自定义模态框，才能真正实现超时自动关闭。

调用流程

完整调用是两阶段的，且第二阶段可能因为用户超时而失败。

阶段发起方动作
01调用方向 /ask 提交问题 X
02服务端原样返回 { question: X, timeout_sec: 15 }
03前端弹窗 + 启动倒计时，用户回答 Y
04a调用方按时回答 → 提交 Y → 服务端返回 { output: Y }
04b调用方超时未答 → 提交 timeout: true → 服务端返回 408
!
超时是终态：一旦超时，本次调用无法恢复，必须重新发起 /ask。这是为了让"用户思考"这件事也有 SLA。

API 端点

两个端点，够用了。

基础地址：

Base URL 
https://api.self-think.dev/v1

请求参数

POST /ask

字段类型说明
inputstring必填。用户的问题 X。任意长度，任意内容。
timeout_secnumber可选。等待用户回答的秒数。默认 15，范围 1–300。设为 0 表示不限时（不推荐）。
localestring可选。弹窗语言，默认 zh-CN。

POST /answer

字段类型说明
answerstring可选。用户回答 Y。空字符串也合法。
cancelledboolean可选。用户是否主动取消。默认 false。
timeoutboolean可选。是否因超时结束。默认 false。为 true 时返回 408。
elapsed_msnumber可选。用户实际思考耗时（毫秒）。

超时机制

用户也需要 SLA。犹豫不决就是 408。

超时倒计时从弹窗出现的那一刻开始，按秒递减。可视化状态：

剩余时间颜色状态
> 5s蓝色正常思考中
3–5s橙色加速提示
< 3s红色临界警告
0s红色自动关闭，返回 408
i
超时后会发生什么：弹窗自动关闭，输入框内容丢弃，调用返回 USER_TIMEOUT。用户必须重新发起请求。
!
为什么要有超时：因为"永远等待"不是 SLA，是 bug。任何严肃的 API 都必须定义超时行为。

调整超时时长：

JavaScript 
// 默认 15 秒
await selfThink("现在是北京时间多少点？");

// 自定义 30 秒，适合复杂问题
await selfThink("人生的意义是什么？", 30);

// 3 秒，适合快问快答
await selfThink("1+1=?", 3);

SLA 与限制

我们对以下指标不做承诺，但可以诚实告知。

  • 延迟：取决于用户打字速度

  • 责任：由用户全责

代码示例

浏览器端 · 完整调用（带超时）

JavaScript 
async function ask(input, timeoutSec = 15) {
  // 1. 提交问题
  const r1 = await fetch('/v1/ask', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ input, timeout_sec: timeoutSec })
  });
  const { question } = await r1.json();

  // 2. 弹窗 + 倒计时，等待用户回答或超时
  const result = await showModal(question, timeoutSec);

  // 3. 提交结果
  const r2 = await fetch('/v1/answer', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      answer: result.answer,
      cancelled: result.cancelled,
      timeout: result.timeout,
      elapsed_ms: result.elapsed
    })
  });

  if (r2.status === 408) {
    throw new Error('USER_TIMEOUT');
  }
  const { output } = await r2.json();
  return output;
}

// 用户 15 秒内回答，返回答案；超时则抛出 408
ask("现在是北京时间多少点？", 15)
  .then(console.log)
  .catch(e => console.error(e.message));

Python

Python 
import requests
import time

def self_think(text, timeout_sec=15):
    # 1. 提交问题
    r1 = requests.post("https://api.self-think.dev/v1/ask",
                        json={"input": text,
                              "timeout_sec": timeout_sec})
    question = r1.json()["question"]

    # 2. 终端交互（弹窗的 CLI 替代），带超时
    print(f"⏱  {timeout_sec}s 内回答：")
    print(question)
    t0 = time.time()

    try:
        answer = input()
    except KeyboardInterrupt:
        answer = None

    elapsed = int((time.time() - t0) * 1000)

    # 3. 提交结果
    if answer is None:
        payload = {"cancelled": True, "elapsed_ms": elapsed}
    else:
        payload = {"answer": answer, "elapsed_ms": elapsed}

    r2 = requests.post("https://api.self-think.dev/v1/answer",
                        json=payload)

    if r2.status_code == 408:
        return "[408] USER_TIMEOUT"
    return r2.json()["output"]

print(self_think("现在是北京时间多少点？"))
